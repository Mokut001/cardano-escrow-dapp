# Cardano Crowdfunding DApp

A fully decentralized crowdfunding application built on the Cardano blockchain using **Plutus V2 smart contracts** and a **React + Lucid** frontend. This project demonstrates how real-world funding challenges can be solved using transparent, trust-minimized DeFi tools powered by Cardano.

## 🚀 Features

- **Create crowdfunding campaigns** with target amounts and deadlines  
- **Pledge ADA** to active campaigns using any supported Cardano wallet  
- **Automatic refunding** if the campaign fails  
- **Secure withdrawal** for campaign creators when funding goals are met  
- **Full on-chain logic** using Plutus V2  
- **Modern frontend** built with React, Vite, TailwindCSS, and Lucid  
- **Deployable on Vercel** without configuration issues  

---

## 🧱 Technology Stack

### **Smart Contract**
- Haskell
- Plutus V2
- Aiken-style validator structure
- On-chain parameterized scripts  
- Serialization with PlutusTx

### **Frontend**
- React + Vite
- Lucid (Cardano transaction library)
- TailwindCSS
- CIP-30 Wallet Integration
